# Stay Easy Tanzania

Website for Stay Easy Tanzania: vacations, transport booking and cargo transport across East and Central Africa.

- `index.html`, `vacations.html`, `transport.html`, `cargo.html`: the site pages
- `img/`: photos and logo
- `_build/build.py`: generates the pages. Run `STANDALONE=1 python3 _build/build.py` from the repo root after editing it.
